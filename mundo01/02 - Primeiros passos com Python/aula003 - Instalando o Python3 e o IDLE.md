**Problema**



Para que você consiga se comunicar com o computador, você precisa de um interpretador.

Nesse caso, o interpretador que vamos conhecer é Python.



* Ele já vem instalado no Linux, e no Mac, mas NÃO no Windows.



**Instalando Python 3**



https://www.python.org/ 



* Baixar versão mais recente.
* No instalador, ativar a parte que fala "Add Python 3 to PATH".
* Para verificar se ta certo, basta abrir o Prompt de Comando e escrever python.
